# Extreme CSE - Audition & Recruitment Portal (2026-27)

Industry-grade Neon Cyberpunk recruitment web portal for **Extreme CSE**, Department of Computer Science & Engineering.

## 🚀 Quick Run Locally
```bash
npm install
npm run dev
```

## 📦 Deploy to Vercel (100% Guaranteed Success)
1. Push this whole folder to a new GitHub repository.
2. In Vercel, click **Add New Project** and select this repository.
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!

## ⚡ Google Sheet Real-time Integration
1. Go to [Google Sheets](https://sheets.new) and create a sheet.
2. Click **Extensions > Apps Script**.
3. Paste the `doPost(e)` script provided in the website's **Sheet Integration** tab.
4. Click **Deploy > New Deployment > Web app > Access: Anyone**.
5. Paste the URL into the portal settings.
