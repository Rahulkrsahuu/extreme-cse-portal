# Extreme CSE (GCET) - Audition & Recruitment Portal 2026-27

Complete, production-ready recruitment web portal designed with the official **Extreme CSE** logo palette:
- **Fire Orange:** `#E84125` / `#FF5533`
- **Carbon Navy:** `#182232`
- **Stealth Matrix:** `#070A10`

## Features:
1. **Student Window:**
   - Audition Registration form with validation & instant Token ID.
   - Public Shortlisting & Selection Board with live search by Name or Roll No.
2. **Admin Command Desk:**
   - Protected with Passcode (`extreme2026`).
   - Live Status Toggler (*Shortlisted*, *Interview Scheduled*, *Selected*, *Not Selected*).
   - Instant 1-click Export to CSV/Excel.
   - Google Sheet Webhook Sync (Google Apps Script).

## 🚀 How to Run Locally:
```bash
npm install
npm run dev
```

## 📦 How to Deploy on Vercel:
1. Push this folder to a GitHub repository.
2. Open Vercel -> "Add New Project" -> Import your repo.
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!
